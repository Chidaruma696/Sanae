Once every few hours Sanae asks GitHub whether a newer release exists and tells you in the status line. Nothing is downloaded until you ask.	数時間ごとに Sanae は GitHub に新しいリリースがあるか確認し、ステータス行で知らせます。指示するまで何もダウンロードしません。
Downloads the latest release binary and replaces this one (needs your password). Sanae is a single file, so this is the whole update.	最新リリースのバイナリをダウンロードして現在のものと置き換えます（パスワードが必要）。Sanae は一つのファイルなので、これで更新は完了です。
The program that builds AUR packages for you: paru or yay. Auto picks whichever is installed.	AUR パッケージをビルドするプログラム: paru または yay。「自動」はインストール済みのものを使います。
