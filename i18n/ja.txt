Extra places to install software from, each off by default. Enter opens the list; every one explains what it is and what it is good for before you turn it on.	ソフトウェアを入れる追加の場所で、既定はすべてオフです。Enter で一覧を開き、有効にする前にそれぞれが何で何に役立つかを説明します。
 is the handy one; 	 が便利、
 is only for security work.	 はセキュリティ作業専用です。
The one most people want. Thousands of AUR programs already compiled by its maintainers, so browsers, editors, games and drivers install in seconds instead of building for minutes. Widely used and handy; still a third party, so a package could break an update.	ほとんどの人が欲しがるもの。数千の AUR プログラムを管理者が既にコンパイル済みなので、ブラウザー、エディター、ゲーム、ドライバーが数分かけてビルドする代わりに数秒で入ります。広く使われて便利ですが第三者製なので、あるパッケージが更新を壊すこともあります。
Flatpak with Flathub: desktop apps that run sandboxed, apart from the system, and update on their own. Good for closed-source or GUI apps you want kept separate from pacman. Built by their publishers, not by Arch.	Flatpak と Flathub：システムから隔離されて動き、自分で更新するデスクトップアプリ。pacman と分けておきたいクローズドソースや GUI アプリに向きます。作者が作っており、Arch ではありません。
Canonical's take on the same idea, from the AUR. On Arch it has fewer apps than Flatpak and is heavier; enable it only if a program you need ships as a snap and nothing else.	同じ発想の Canonical 版で、AUR から入ります。Arch では Flatpak よりアプリが少なく重め。必要なプログラムが snap でしか配布されていないときだけ有効にしてください。
A desktop-tuned kernel (linux-lqx) for smoother audio, gaming and video when the machine is busy. Nice on a workstation, but you must add it to your bootloader after installing. A third-party kernel.	デスクトップ向けに調整されたカーネル（linux-lqx）。負荷が高いときの音声、ゲーム、動画を滑らかにします。ワークステーションに向きますが、インストール後にブートローダーへ追加が必要です。第三者製カーネルです。
Arch's own packages rebuilt for newer CPUs (x86-64-v3 or v4) for a small speed gain. Helps only on a 2015-or-later CPU and is safe to skip. Community project; its packages lag Arch by a few hours.	Arch 自身のパッケージを新しい CPU（x86-64-v3 または v4）向けに再ビルドし、わずかに高速化します。2015 年以降の CPU でしか効果がなく、飛ばしても問題ありません。コミュニティ企画で、パッケージは Arch より数時間遅れます。
Adds 2 800+ security and penetration-testing tools: scanners, exploits, forensics, wireless. It is meant for security work, the tools are dual-use, and the repository is large.
